# 用 pandas 玩转数据：从加载到可视化的一条龙 🐝

地基打好之后（见上篇 Phase 0），我马上进了真刀真枪的环节——**数据处理（Phase 1）**。这一阶段的工具核心是 `pandas`，江湖人称"Python 里的 Excel 加强版"。

我用一条主线串起它：**把数据想象成一张超级表格，pandas 就是专门收拾这张表的全套工具箱。** 从把表拿进门，到把它洗得干干净净、排好队、算好账、拼成一张大表、最后画成图，一共七个环节。

## 一、加载：把数据"搬"进 Python

### 用大白话讲

数据平时躺在各种文件里（csv、excel、json……）。"加载"就是**把这张表从文件里搬进 Python 的内存**，变成 pandas 能操作的样子（一个叫 `DataFrame` 的对象）。

`pd.read_csv("文件.csv")` 一句话就把 csv 搬进来。Excel 用 `read_excel`，json 用 `read_json`。不同格式，不同"搬法"，但目标一样：让数据进入程序。

### 我的理解 & 踩坑

- `DataFrame` 这名字第一次见很唬人，其实就是"带行列标签的二维表"，跟 Excel 工作表几乎一回事。
- 路径写错是最常见的坑。相对路径是"相对于你跑命令的位置"，不是"相对于文件位置"——这点我栽过，后来养成习惯先 `print(数据.shape)` 确认真的加载进来了。

## 二、看数据：先摸清这张表长啥样

### 用大白话讲

表搬进来，别急着动手。先** reconnaissance（侦察）**——看看它多大、有哪些列、长什么样。

几个常用"看一眼"的动作：
- `df.shape`：几行几列（表的身材）
- `df.head()`：看前几行（表头长啥样）
- `df.info()`：每列什么类型、有没有空值（体检报告）
- `df.describe()`：数字列的统计摘要（平均值、最大最小……）

### 我的理解 & 踩坑

- 我以前拿到表就直接算，结果算出来一堆 `NaN`（空值），还不知道哪来的。现在规矩变成：**先看 info() 查空值，再动手**。
- `describe()` 是快速了解"这堆数大概什么范围"的神器，比肉眼扫强太多。

## 三、清洗：把脏东西挑出去

### 用大白话讲

真实数据都很脏：有空格、有重复行、有缺失值、有格式乱的。**清洗**就是"大扫除"——

- 缺值处理：`dropna()` 删掉有空的行，`fillna(值)` 用某个值补上
- 去重：`drop_duplicates()` 把一模一样的行删掉
- 改格式：把"字符串型的数字"转成真数字（`astype`）之类的

### 我的理解 & 踩坑

- 删空值还是填空值，是个**业务判断**，不是随便选。如果这列空了就代表"没记录"，删掉合理；如果是"漏填了"，可能该补。我先问自己"这个空代表什么"再决定。
- 清洗顺序有讲究：一般先去重、再处理空值，不然可能白洗。

## 四、筛选与排序：挑出你要的行，排好队

### 用大白话讲

- **筛选**：按条件挑行。比如"只要年龄大于 18 的"——`df[df["年龄"] > 18]`。中括号里放一个"True/False 的 masks（面具）"，pandas 就只留下面具为 True 的行。
- **排序**：`sort_values("列名")` 按某列排。`ascending=False` 是降序（从大到小）。

### 我的理解 & 踩坑

- 筛选的"面具"概念是我理解的关键：你不是在写"如果"，而是在造一张"哪些行要留下"的名单。
- 多个条件用 `&`（且）和 `|`（或），但**每个条件都要加括号**，不然运算符优先级会坑你。我中过招。

## 五、聚合：分组算账

### 用大白话讲

"按某类分组，然后每组算个总数/平均数"——这就是聚合。`groupby("地区")["销量"].sum()` 的意思是：按地区分组，算每个地区的销量总和。

很像 Excel 的"数据透视表"：把表按某个维度折叠起来，每个组吐出一个汇总数字。

### 我的理解 & 踩坑

- `groupby` 后面一定要跟一个"算啥"（sum/mean/count），光 groupby 不聚合等于只分组不干活。
- 这是数据分析里最常用、也最出彩的一步——能从原始数据里榨出"趋势"和"结论"。

## 六、合并：把几张表拼成一张大表

### 用大白话讲

现实里数据分散在多张表里：一张是"用户信息"，一张是"订单记录"。要一起分析，得**拼起来**。

- `merge`：像 VLOOKUP，按"键"（比如用户ID）把两张表横向拼
- `concat`：把结构相同的表上下叠起来

### 我的理解 & 踩坑

- `merge` 的 `on` 参数指定"按哪列对齐"，这列在两个表里得有对应关系，否则拼出来的要么空要么乱。
- 拼之前先确认两张表的"键"真的对得上，不然拼完发现对不上号，debug 很痛苦。

## 七、可视化：让数据"开口说话"

### 用大白话讲

算完一堆数，人脑很难直接看懂。画成图，趋势一眼就出来。`pandas` 自带 `.plot()`，配合 `matplotlib` 能画出折线、柱状、饼图等。

### 我的理解 & 踩坑

- 中文乱码是经典坑：matplotlib 默认不支持中文，得手动指定中文字体，否则标题变成方块。我第一次画图全是□□□。
- 图不是越花越好，**一张图只讲一件事**，比堆一堆信息清楚得多。

## 小结：七步成诗

把这七个环节连起来，就是数据处理的完整一条龙：

```
加载 → 看数据 → 清洗 → 筛选排序 → 聚合 → 合并 → 可视化
```

它们不是孤立的招式，而是**一套组合拳**。真实任务往往是："加载一堆脏数据 → 洗干净 → 按条件挑 → 分组算账 → 拼上别的表 → 画图讲结论"。

下一站我打算往**爬虫**或**运维**方向走——不管是哪个，pandas 这套数据处理内功都是底层兵器，到哪里都好使。🐝
