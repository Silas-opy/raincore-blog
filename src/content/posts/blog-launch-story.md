# 我的博客上线记 🚀

今天干成了一件大事：**我的个人博客 silasrxs.top 正式上线了**。

你可能想不到，这个博客的起点，其实是别人开源的一个模板。从一个「fork 来的空壳」，到「真正属于我的网站」，中间发生了不少故事。写下来留个纪念，也给想折腾博客的朋友一点参考。

## 起点：一个 fork

事情很简单——我在 GitHub 上看到一个很漂亮的博客主题（[Firefly](https://github.com/CuteLeaf/Firefly)，基于 Astro），fork 了过来，想着「改改就能用」。

结果发现，这个模板的前任主人留下了一堆痕迹：标题是别人的名字，头像是别人的 QQ，友链里挂满了别人的朋友，甚至还有个「视奸我在干嘛」的组件……好家伙，这哪是博客，这是别人的私人空间。

于是，一场「大扫除」开始了。

## 大扫除：把别人的家改成我的家

要改的东西比想象中多：

- **标题** → 「Silas若虚生的个人博客」
- **横幅图** → 换成我喜欢的洛天依舞台图
- **打字机文字** → 改成英文欢迎语（原来那句是前任写给别人的情话）
- **头像、QQ、微信、GitHub、B站** → 全部换成我的
- **打赏码** → 删掉（前任的收款码，不删等着别人给我前任打钱吗）
- **文章** → 前任的 4 篇全删，换成我自己的
- **友链** → 前任的 10 个朋友……这个我纠结了一下，最后先保留着，又加了两个我常逛的社区

折腾到一半我才发现，原来「个人博客」里藏着这么多「个人」。

## 第一个坑：音乐太大

我本来想把 600 多首歌塞进博客当背景音乐——结果一算，2.5GB。

GitHub 单文件上限 100MB，Cloudflare 部署也有体积限制。2.5GB 的音乐根本传不上去。

最后我换了思路：**改用网易云的在线歌单**，不占空间、不用上传、还能在线播放。省心多了。

## 第二个坑：git 推送卡死

代码改好了，要推到 GitHub 上部署。结果 `git push` 一直卡住——原来是我的环境里有个「凭据选择器」弹窗，在非交互状态下会一直等，最后超时被杀掉。

折腾半天，最后是手动在弹窗里登录 GitHub 授权，才推上去。

## 第三个坑：域名报错连环炮

部署到 Cloudflare 后，绑域名 `silasrxs.top` 一路报错：

- **Error 1014** —— 域名解析到了别人的账号
- **Error 1016** —— 域名指向了一个空地址

排查到最后，原因是我一开始用了「Route（路由）」而不是「Custom Domain（自定义域）」。换成 Custom Domain 之后，一切就通了。

还有个彩蛋：Cloudflare 给的临时地址 `xxx.workers.dev` 在国内是**打不开的**（被墙）。所以绑自己的域名不是「锦上添花」，而是「必须的」。

## 上线那一刻

当浏览器里终于出现我的博客——横幅是我的图，标题是我的名字，头像是我——那种感觉还挺奇妙的。

一个 fork 来的模板，就这样变成了「我的网站」。

## 给也想折腾的人的小建议

1. **fork 模板后，先做一次「前任清理」**：搜一遍旧作者的名字、账号、邮箱，能清的全清掉
2. **大文件别往仓库塞**：音乐、视频用外部链接或云存储
3. **部署选对平台**：域名在 Cloudflare，就直接用 Cloudflare Pages/Workers，最省事
4. **报错别慌**：Cloudflare 的 1014/1016 基本都是 DNS 记录配错，查一下就能解决
